# RB-06 — Cryptographic Key Compromise

## 1. Scenario Identification

**Runbook ID:** RB-06  
**Scenario:** Cryptographic Key Compromise  
**Category:** Security  
**Severity:** P1 — Critical

### Affected Components

- AWS KMS
- KMS customer managed keys
- AWS Secrets Manager
- Database credentials
- API keys
- Partner certificates
- TLS certificates
- EKS workloads
- Aurora PostgreSQL
- DynamoDB
- ElastiCache Redis
- Amazon MSK
- S3
- Application APIs
- Partner bank integrations
- CloudTrail
- GuardDuty
- IAM
- Monitoring and alerting

### Scenario Description

A cryptographic key, credential, certificate, or other secret used by PaySecure is suspected or confirmed to be compromised.

The compromise may involve:

- Unauthorized KMS key usage
- Exposure of an API key
- Exposure of database credentials
- Compromise of partner certificates
- Unauthorized Secrets Manager access
- TLS certificate compromise
- IAM credential compromise
- Unauthorized encryption or decryption activity
- Exposure of credentials through application logs or configuration

Because cryptographic material protects sensitive payment and infrastructure data, the incident must be contained without destroying forensic evidence or causing unnecessary service disruption.

### Recovery Objectives

- **Target RTO:** < 5 minutes
- **Target RPO:** < 1 minute
- **Primary Region:** Mumbai (`ap-south-1`)
- **Recovery Region:** Hyderabad (`ap-south-2`)
- **Primary Secret Store:** AWS Secrets Manager
- **Primary Key Management:** AWS KMS

## 2. Detection Mechanism

### Primary Detection Signals

| Signal | Threshold | Severity |
|---|---:|---|
| Unauthorized KMS API activity | Any confirmed event | P1 |
| Unauthorized Secrets Manager access | Any confirmed event | P1 |
| Unknown IAM principal using key | Any event | P1 |
| Unexpected `Decrypt` activity | Any anomalous activity | P1 |
| Unexpected `GetSecretValue` | Any anomalous access | P1 |
| GuardDuty credential finding | Any high/critical finding | P1 |
| Certificate compromise | Any confirmed compromise | P1 |
| API authentication failures | >5% for 2 minutes | P1 |
| Database authentication failures | >5% for 2 minutes | P1 |
