# RB-11 - Ransomware Attack on Infrastructure

## 1. Scenario Identification
**ID:** S11 | **Category:** Security | **Severity:** P1-Critical | **Components:** EKS nodes, CI/CD, registries, credentials, backups, both regions.

## 2. Detection Mechanism
Page on GuardDuty high findings, mass file modification, disabled agents, unexpected privileged activity, or more than 90% abnormal node CPU for 5 minutes.

## 3. Impact Assessment
Potential compromise of application images, infrastructure, secrets, and data. Do not activate a possibly compromised DR region; preserve clean recovery points and quantify affected systems.

## 4. Immediate Response (0-2 minutes)
1. **IC (15s):** Declare security P1 and engage CISO/forensics.
2. **Security (20s):** Run `aws guardduty list-findings --detector-id $env:PAYSECURE_DETECTOR_ID --region ap-south-1`.
3. **Platform (20s):** Run `kubectl get nodes -o wide` and isolate suspected nodes.
4. **IAM (30s):** Disable compromised CI/CD principals and revoke sessions.
5. **IC (30s):** Freeze deployments, image promotion, and replication of suspicious artifacts.

## 5. Diagnostic Steps (2-5 minutes)
6. **Security (20s):** Run `aws cloudtrail lookup-events --lookup-attributes AttributeKey=Username,AttributeValue=$env:COMPROMISED_USER --max-results 50`.
7. **Platform (20s):** Run `kubectl get pods -A -o wide` and record evidence.
8. **Registry owner (20s):** Run `aws ecr describe-images --repository-name $env:PAYSECURE_REPOSITORY --region ap-south-1`.
9. **Backup owner (30s):** List clean immutable backups and their checksums.
10. **IC (20s):** If only one node is affected, isolate and rebuild; if CI/CD or images are affected, use trusted IaC and clean artifacts; if both regions are compromised, invoke third-region rebuild and regulatory response.

## 6. Failover Procedure (5-15 minutes)
11. **Platform (30s):** Cordon/isolate with `kubectl cordon $env:COMPROMISED_NODE` and remove network access through the approved control.
12. **IAM (30s):** Rotate secrets with `aws secretsmanager rotate-secret --secret-id $env:PAYSECURE_SECRET_ID --region ap-south-1`.
13. **Security (30s):** Confirm clean image digest with `aws ecr describe-images --repository-name $env:PAYSECURE_REPOSITORY --image-ids imageDigest=$env:CLEAN_DIGEST --region ap-south-2`.
14. **Platform (60s):** Rebuild only from reviewed Terraform/Kubernetes sources and apply with `kubectl apply --server-side --dry-run=server -f configs/kubernetes` before deployment.
15. **CISO (30s):** Approve restoration after forensic and backup integrity gates; notify CERT-In/RBI when required.

## 7. Communication Protocol
Use a restricted incident bridge, executive update, merchant advisory only after confirmed impact, and regulator/CERT-In notices through the CISO. Keep communication out-of-band if Slack/email may be compromised.

## 8. Verification and Validation
Clean image hashes, IAM audit, GuardDuty status, immutable backup restore, pod integrity, secrets rotation, and synthetic payment all pass before traffic resumes.

## 9. Rollback Procedure
If restored artifacts fail integrity checks, isolate them, stop traffic, and return to the last verified clean recovery point. Never restore from the suspicious region or reuse compromised credentials.

## 10. Post-Incident Review
Preserve forensic chain of custody, reconstruct access, complete five-whys, document notifications, and harden CI/CD, IAM, backups, and node isolation.
