# RB-11 — Ransomware Attack on Infrastructure

## 1. Scenario Identification

| Field | Details |
|---|---|
| **Runbook ID** | RB-11 |
| **Scenario** | Ransomware Attack on Infrastructure |
| **Category** | Security / Infrastructure |
| **Severity** | P1-Critical |
| **Primary Region** | AWS Mumbai (`ap-south-1`) |
| **DR Region** | AWS Hyderabad (`ap-south-2`) |
| **Affected Components** | EKS, EC2 worker nodes, EBS volumes, Aurora PostgreSQL, DynamoDB, ElastiCache, MSK, S3, IAM, KMS, Secrets Manager |
| **Target RTO** | < 5 minutes for customer-facing service recovery |
| **Target RPO** | < 1 minute for critical transaction data |
| **Primary Objective** | Contain the compromise, protect data, prevent propagation, and restore service from trusted infrastructure |

### Scenario Description

A ransomware attack compromises one or more infrastructure components within the PaySecure environment. Indicators may include encrypted files, unexpected file extensions, disabled security agents, unauthorized privileged activity, mass data modification, suspicious encryption processes, deleted backups, or abnormal API activity.

The response prioritizes **containment before recovery**. Operators must not restore potentially compromised resources into the production environment until the security team confirms that the recovery source is trusted.

The Hyderabad DR region is treated as a potentially clean recovery environment only after its integrity and credentials have been validated.

## 2. Detection Mechanism

### Primary Detection Sources

| Detection Source | Indicator | Trigger |
|---|---|---|
| GuardDuty | Malware, credential abuse, unusual API activity | High/Critical finding |
| CloudTrail | Unauthorized destructive API calls | Delete/disable actions outside approved change window |
| EKS/Prometheus | Abnormal CPU/process behavior | >90% CPU for 5 minutes or unexpected workload |
| EBS/EC2 | Unexpected encryption/file modification | Multiple hosts showing file changes |
| S3 | Mass object modification/deletion | Significant deviation from normal write rate |
| Aurora | Unexpected DDL/DML activity | Unapproved destructive activity |
| DynamoDB | Abnormal write/delete volume | >3x normal baseline |
| IAM | Privilege escalation | Unauthorized role/policy modification |
| KMS | Abnormal key usage | Unexpected decrypt/data-key activity |
| Security alerts | Malware/ransomware signature | Any confirmed ransomware indicator |
