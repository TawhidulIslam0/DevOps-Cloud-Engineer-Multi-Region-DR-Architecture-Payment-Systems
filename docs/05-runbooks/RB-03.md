# RB-03 — DNS Poisoning / DNS Infrastructure Failure

## 1. Scenario Identification

**Runbook ID:** RB-03  
**Scenario:** DNS Poisoning / DNS Infrastructure Failure  
**Category:** Security / Infrastructure  
**Severity:** P1 — Critical

### Affected Components

- Amazon Route 53
- Route 53 health checks
- DNSSEC
- PaySecure public DNS records
- Application Load Balancers
- AWS WAF
- Payment API endpoints
- Merchant integrations
- Bank/partner integrations
- TLS certificates
- CloudTrail
- GuardDuty
- Monitoring and alerting
- Alternative DNS provider

### Scenario Description

A DNS security or infrastructure incident causes PaySecure's production DNS records to resolve incorrectly, become unavailable, or redirect users toward an unauthorized endpoint.

Possible causes include:

- DNS record compromise
- Unauthorized Route 53 changes
- DNSSEC validation failure
- Incorrect DNS deployment
- Route 53 infrastructure disruption
- Registrar or delegation problems
- Incorrect ALB target
- Unexpected IP address resolution
- External DNS poisoning

The primary objective is to determine whether the problem is a DNS configuration issue, an AWS DNS infrastructure problem, or an active security incident, then restore trusted DNS resolution without introducing additional risk.

### Recovery Objectives

- **Target RTO:** < 5 minutes
- **Target RPO:** < 1 minute
- **Primary Region:** Mumbai (`ap-south-1`)
- **Recovery Region:** Hyderabad (`ap-south-2`)
- **DNS Provider:** Amazon Route 53
- **Emergency DNS Provider:** Approved alternative DNS provider
- **Primary API Endpoint:** `api.paysecure.example`

## 2. Detection Mechanism

### Primary Detection Signals

| Signal | Threshold | Severity |
|---|---:|---|
| DNS resolution failure | >5% of probes fail | P1 |
| Unexpected API IP | Any unauthorized IP | P1 |
| DNSSEC validation failure | Sustained failure | P1 |
| API HTTP 5xx | >5% for 2 minutes | P1 |
| TLS certificate mismatch | Any confirmed mismatch | P1 |
| Merchant DNS complaints | 3+ independent reports | P1 |
| Unauthorized Route 53 change | Any confirmed change | P1 |
| API success rate | <99% for 2 minutes | P1 |

### CloudWatch / Monitoring Configuration

Monitor:

- Route 53 health-check status
- Route 53 configuration changes
- ALB `HTTPCode_ELB_5XX_Count`
- ALB `HTTPCode_Target_5XX_Count`
- Application transaction success rate
- TLS handshake failures
- DNS resolution from multiple geographic probes
- Prometheus API availability
- CloudTrail Route 53 events
- GuardDuty security findings
