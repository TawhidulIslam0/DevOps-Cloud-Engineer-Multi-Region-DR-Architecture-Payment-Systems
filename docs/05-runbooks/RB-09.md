## 1. Scenario Identification

### Scenario

TLS certificates for PaySecure's payment API domain expire, are incorrectly
configured, or are served with an incomplete/invalid certificate chain.

This can cause HTTPS clients to reject connections to the payment API.

The project brief requires this runbook to address:

- Prevention monitoring
- Emergency certificate renewal
- Trust-chain reestablishment
- Cross-client testing
- Prevention automation

### Affected Components

Potentially affected:

- Route 53
- Application Load Balancer
- HTTPS listeners
- Payment API
- EKS ingress
- Merchant-facing APIs
- Partner/bank integrations
- Webhook endpoints
- API clients
- ACM certificates
- Secrets Manager where certificate material is stored
- CloudWatch
- Prometheus
- Grafana
- PagerDuty

Certificate expiration <30 days
